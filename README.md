A single one-line entry, written by `main.ts` to `/output/entry.txt` — nothing else.

## The line

> My cat sat on the router during my job interview. The Wi-Fi died, but his career survived.

## Why this line

- **A mechanism nobody owns yet:** the field saturates with keyboards, objects knocked off tables, gravity tests and 3 a.m. zoomies. Nothing in it sits the cat on the router in the middle of a job interview.
- **Misdirection that lands:** the first death in the line is the Wi-Fi's, and the reader braces for the second to be the job. The survivor is the cat's career — a career the cat never applied for.
- **One act, one consequence, one punch:** a single cat behaviour, a human disaster, and the turn pays off on the last word.
- **Retellable:** no setup outside the line, no heard-it-before pun — it reads like something that happened to a friend.
- **Tight:** 90 characters against the 200-character gate.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
